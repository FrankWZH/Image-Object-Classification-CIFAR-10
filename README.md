# 📖 Project Overview

This project focuses on image object classification using the **CIFAR-10 dataset**.  
The goal is to build and evaluate machine learning/deep learning models capable of accurately classifying images into 10 different categories.

---

# 🧠 CIFAR-10 Classes

| Class | Description |
|------|-------------|
| ✈️ Airplane | Aircraft images |
| 🚗 Automobile | Vehicle images |
| 🐦 Bird | Bird category |
| 🐱 Cat | Cat category |
| 🦌 Deer | Deer category |
| 🐶 Dog | Dog category |
| 🐸 Frog | Frog category |
| 🐴 Horse | Horse category |
| 🚢 Ship | Ship images |
| 🚚 Truck | Truck images |

---

# 📊 Dataset Information

| Property | Value |
|----------|-------|
| Total Images | 60,000 |
| Training Images | 50,000 |
| Testing Images | 10,000 |
| Image Size | 32 × 32 |
| Classes | 10 |

# ⚙️ Installation

## Clone the Repository

```bash
git clone https://github.com/FrankWZH/Image-Object-Classification-CIFAR-10.git
```

## Move into the Project Folder

```bash
cd Image-Object-Classification-CIFAR-10
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

# 🚀 Running the Project

Run the main script:

```bash
python main.py
```
